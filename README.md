# Dystiny Question Preflight

A browser-private activation aid for turning a broad idea into a focused research question that is easier to explore as a visual evidence path in Dystiny.

It does not save or transmit the draft before the user chooses to open it on Dystiny. Visitors can browse the public topic map, review how the product works, choose a source expectation, or follow a research path before deciding whether to open Search. Crawlable example paths reduce blank-page friction without creating social, listing, email, form, or other outreach.
