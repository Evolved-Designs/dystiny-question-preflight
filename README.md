# Dystiny Question Preflight

A browser-private activation aid for turning a broad idea into a focused research question that is easier to explore as a visual evidence path in Dystiny.

The standalone deployment is retired. Dystiny's maintained native [Question Guide](https://dystiny.com/question-guide/) now carries the question-shaping path; this repository preserves the earlier browser-private source.

[Open the native Question Guide](https://dystiny.com/question-guide/)
