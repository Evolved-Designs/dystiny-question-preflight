    Creative research path

    Start with the object, then open the wider question.

    A work of art, archive item, or performance can be a strong starting node. Record what the collection says, separate observation from interpretation, then ask what people, places, techniques, and histories connect around it.

    Browse Dystiny Explore Find a reusable Smithsonian source object
    1. Anchor the source.Capture the creator, title, date, collection, object record, and usage terms.
    2. Name the gap.Ask what is documented, what is interpretation, and what context is still missing.
    3. Open a connection.Shape a question about influence, technique, place, audience, preservation, or change over time.

    Event technology path

    Compare the ticket journey before choosing the tool.

    A ticketing decision connects checkout, attendee data ownership, refunds, mobile access, confirmations, and the door experience. Start with those objects and responsibilities, then compare implementation choices against current documentation.

    Open the ticketing decision in Dystiny Browse Explore Technology first
    1. Map the journey.List the event, ticket types, inventory, buyer, attendee, payment, confirmation, check-in, and fallback.
    2. Separate claims from evidence.Use current provider documentation for checkout behavior and accessibility guidance for mobile controls.
    3. Name the operating tradeoff.Compare speed to launch, ownership, support burden, data access, and what happens when the normal path fails.

    Current starting sources: Stripe Checkout documentation and W3C target-size guidance.

    Visual evidence path

    Trace what an image shows, where it came from, and what changed.

    A visual can be evidence, illustration, interpretation, or decoration. Start with the original record and observable details, keep inference separate, then follow the people, process, place, date, edits, and usage context around it.

    Open a visual-provenance question Browse Explore first
    1. Anchor the record.Find the original page or collection entry, creator, date, caption, identifier, and usage terms.
    2. Separate observation.Record what is visibly present before adding an interpretation, attribution, or claim about intent.
    3. Check the history.Look for edits, derivatives, missing context, corroborating records, and Content Credentials where they exist.

    Current starting sources: C2PA Content Credentials specifications and W3C image-alternative guidance.
